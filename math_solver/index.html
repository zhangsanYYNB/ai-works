键盘与公式编辑

直接输入，或点按虚拟键盘。分数、根号、幂支持公式编辑；方向键移动光标，Tab 跳到下一处占位。长按带角标的按键约 0.4 秒，滑动到目标符号后松手，也可点选弹出的符号。

按 Enter 求解；文本输入中 Shift + Enter 换行。公式 / 文本可切换，方程组、矩阵和带逗号的函数建议使用文本输入。计算历史和收藏保存在当前浏览器。

表达式语法

2x + 3(x+1)允许省略乘号x^2 - 5x + 6 = 0方程；<、>、<=、>= 为不等式2x+y=7; x-y=2分号 / 换行分隔线性方程组sqrt(2), nthRoot(8,3)平方根与 n 次根ln(e), log(8,2), log10(100)自然对数、指定底数、常用对数sin(pi/6), asin(0.5)三角 / 反三角；RAD / DEG 切换单位combinations(10,3), 5!组合数与阶乘[1,2;3,4], inv([1,2;3,4])矩阵与矩阵函数1, 2, 3, 4, 5统计数据，可加方括号diff(x^3,x), integrate(x^2,x)也可以选择求导或积分模式sum(k^2,k,1,10)有限求和；product 为有限连乘5 cm to inch, 32 degF to degC单位换算，数值和单位用空格分开

支持的计算

科学计算、分数与复数、代数化简 / 展开 / 因式分解、单变量多项式方程、非多项式方程的区间实根搜索、线性方程组、多项式与有理式不等式、导数、不定 / 定积分、极限、矩阵与向量、描述统计、单位换算，以及最多六条实函数的交互式图像。

结果如何阅读

能给出符号结果时显示精确答案，同时补充近似值。步骤根据具体计算生成；数值求根或数值积分会说明方法和范围。复杂表达式可能超出本地符号引擎的能力，此时会明确提示。积分常数、定义域和不可取的分母零点请留意结果说明。
