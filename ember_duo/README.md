# 星火双行 / Ember & Echo

直接打开 `index.html` 即可游玩。所有脚本和图像纹理均在本地，无需构建、服务器或在线 CDN。手机和平板建议横屏，支持单人或本地双人合作，不包含网络联机。

## 冒险内容

六个世界各八关，共 48 关：苔光森林、回声遗迹、霜镜雪原、赤焰熔炉、风暴群岛、星穹圣域。每个世界最后一关有一场首领战。关卡采用预设路线组合，包含高低支路、钥匙门、升降平台、弹簧、碎裂平台、冰面、锯刃、定时激光和可击碎方块。

角色可以二段跳、冲刺、发射星火弹和踩踏敌人。持续按住攻击可连续射击；短按跳跃可降低跳跃高度。冲刺有冷却时间，期间可以穿越攻击并撞击敌人。首领会预告攻击，并在攻击后的休息阶段暴露核心。

每关三枚星核，关卡出口不要求收齐，允许先通关再回收。获得星章的条件分别是：通关、收齐三枚星核、在目标时间内零倒下通关。各次挑战的星章会合并保留，共 144 枚。

## 键盘

| 操作 | P1 | P2 |
| --- | --- | --- |
| 左右移动 | A / D | 左 / 右方向键 |
| 跳跃、二段跳 | W / 空格 | 上方向键 / 小键盘 0 |
| 发射星火弹 | J | / 或小键盘 1 |
| 冲刺 | K / 左 Shift | . 或小键盘 2 / 右 Shift |
| 暂停、继续 | Esc / P | 共用 |
| 召回同伴 | R | 共用 |

单人模式也可以使用 P2 的方向键和动作按键。使用 `KeyboardEvent.code`，不依赖输入法字符；键盘自身的多键冲突限制仍然适用，可让另一名玩家使用触屏。

## 触屏与合作

触屏按钮支持多点同时按下，并可与键盘同时操作。双人模式为两名玩家各提供一组移动和动作按钮；设备支持的触点数量由硬件决定。顶部手掌按钮可切换触屏面板，设置中可以选择自动显示。

两名玩家共享本关星屑、星核、钥匙和检查点，生命与冲刺独立。抵达新检查点会恢复存活队员生命，倒下后会在检查点或处于安全地面的队友身边复活，没有次数限制。

同屏镜头会随两人间距缩放。领跑者在稳固地面时可以使用召回按钮或 R 会合；距离过大时会自动尝试安全会合。两人均抵达星门才能结束关卡。所有路线都可单人完成，没有必须双人触发的机关。

## 设置与存档

声音默认关闭，可使用顶部音量按钮开启。设置提供音乐、音量、触屏、粒子与震屏、生命加护。生命加护将生命上限从三格提高至五格。音乐与音效由 Web Audio 合成，不加载音频文件。

通关记录、已获得星章、最佳时间、下一关位置和设置保存在本浏览器的 localStorage。关内临时状态不跨刷新保留；刷新后重新开始对应关卡。隐私模式或存储权限限制可能使进度只能临时保留，设置页会显示提示。不同浏览器以及 file/HTTP 访问方式各自拥有独立存档。

## 文件

- `index.html`、`css/style.css`：界面与响应式触屏布局。
- `js/game.js`：Phaser Arcade 物理、战斗、合作、首领与关卡循环。
- `js/levels.js`：六世界及 48 关预设路线。
- `js/art.js`：本地 Canvas 绘制角色、道具、地形和多层视差景物。
- `js/systems.js`：输入、存档和合成音频。
- `js/ui.js`：菜单、地图、HUD、设置和结算。
- `vendor/phaser.js`：Phaser 3.90.0，MIT，见 `PHASER-LICENSE.md`。
- `vendor/lucide.js`：Lucide 图标，见 `LUCIDE-LICENSE.txt`。
