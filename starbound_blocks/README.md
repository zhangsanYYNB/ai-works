# 星际方块：远星回响

融合体素采矿、自由建造与异星探索的单人网页小游戏。采用原创程序化美术，不包含 Minecraft 或 No Man's Sky 的代码、美术或品牌资产，也不是这两款游戏的完整复刻。

## 运行

打开本目录的 `index.html`，或从仓库主页面第一个导航卡片进入。整个目录需要保持完整；无需安装、打包或联网下载运行依赖。需要支持 WebGL 的现代浏览器，建议开启硬件加速。静态托管与 GitHub Pages 均可运行。

共有四颗有限大小、按固定种子生成的星球，每颗地表约 60 × 60 格。星际旅行通过星图选择目的地及跃迁动画完成，不是开放宇宙中的自由驾驶模拟。

## 探险流程

1. 在青岚星着陆区附近采集铁、碳和辉光晶体，在背包制造终端修复飞船引擎。
2. 到飞船附近打开星图，消耗燃料前往其他星球。燃料可制造，也可用研究点兑换补给。
3. 扫描生物与矿物，获得研究点。探索青岚星、霜汐星和赤烬星的遗迹，各收集一枚碎片。
4. 升级采集器、环境防护和喷气背包，对抗异星哨兵，开采金与星核矿。
5. 制造跃迁核心，前往弥光星遗迹启动星门。完成后仍可自由采矿、建造与探索。

- 方块采集有持续进度，采集器也能攻击哨兵；建造方块可以拆除回收。
- 基岩、飞船停机坪和遗迹基座不可拆除，重要通道不能放置方块，避免流程被堵死。
- 靠近飞船会补充氧气与护盾；读取后的遗迹也能充能。环境风暴会加快氧气消耗。
- 护盾耗尽会紧急救援回船，最多扣除 50 研究点，物品和建筑不会丢失。
- 扫描有 7 秒冷却，同一样本不能重复领取发现奖励；扫描可取得少量碳，制造氧气不必等待随机掉落。

## 操作

| 操作 | 键鼠 | 触屏 / 触控笔 |
| --- | --- | --- |
| 移动 | WASD / 方向键；Shift 加速 | 左侧摇杆 |
| 转向 | 点击画面锁定鼠标后移动；不支持锁定时拖动 | 在世界画面上拖动 |
| 跳跃 / 飞行 | 空格，持续按住启动喷气背包 | 右侧上箭头，持续按住飞行 |
| 采矿 / 攻击 | 选中采集器，长按左键 | 选中采集器，长按镐按钮 |
| 建造 | 选中方块后左键，或右键放置；采集器右键默认放合金 | 选择底部方块，再按加号按钮 |
| 切换工具 / 方块 | 数字 1–6 / 鼠标滚轮 | 点击底部快捷栏 |
| 扫描 | F / 雷达按钮 | 雷达按钮 |
| 飞船 / 遗迹交互 | E / 屏幕上的交互按钮 | 屏幕上的交互按钮 |
| 背包制造 / 星图 / 记录 | Tab / M / J | 顶部相应图标 |
| 补充氧气 / 修复护盾 | R / H，或背包按钮 | 背包里的对应按钮 |
| 暂停 | Esc / 暂停按钮 | 顶部暂停按钮 |

触屏依据 `navigator.maxTouchPoints` 与 `any-pointer: coarse` 检测，不依赖操作系统名称。Windows 触屏电脑同样能使用摇杆，多指可同时移动、转向、采矿或飞行，键盘和鼠标始终保留。暂停菜单可手动开关触屏控制，设置会保存。手指取消、窗口失焦、切换菜单时会清理按下状态。

## 存档

- 自动保存在当前浏览器的 `localStorage`，每 15 秒及关键进度变化时保存。
- 暂停菜单提供手动保存、JSON 导出与导入、二次确认的新探险。
- 各星球方块改动、背包、升级、发现、任务进度和设置会保存。
- 不同浏览器、站点地址、HTTP 和 `file:` 的存档彼此独立。迁移地址或清理浏览器前请导出。
- 浏览器禁用本地存储或存储空间耗尽时会提示；不要把浏览器存储当成唯一备份。

## 文件

- `index.html`：入口及 HUD / 弹窗骨架。
- `css/style.css`：桌面、竖屏、横屏与触屏布局。
- `js/data.js`：资源、配方、星球配置、确定性随机数与存档校验。
- `js/world.js`：体素地形、分块网格、纹理、星球、飞船、遗迹、生物和哨兵。
- `js/game.js`：Cannon 物理、采矿、建造、输入、战斗、生存、存档和主循环。
- `js/ui.js`：制造、星图、发现记录、任务、设置和存档管理。
- `vendor/`：锁定版本的本地依赖及许可。
- `tests/`：规则测试及浏览器冒烟检查。

静态装饰通过 Three.js `InstancedMesh` 合并绘制，地形按 10 × 10 分块更新；Cannon 仅同步玩家周围的碰撞体。低性能设备可在暂停菜单关闭高精度渲染。

## 验证

规则测试无需安装依赖：

```sh
node --test starbound_blocks/tests/rules.test.cjs
```

可选浏览器测试需要 `playwright-core` 和 Chromium，以及根目录的静态 HTTP 服务：

```sh
GAME_URL=http://127.0.0.1:8765/starbound_blocks/index.html \
PLAYWRIGHT_PATH=/path/to/playwright-core \
CHROMIUM_PATH=/path/to/chromium \
node starbound_blocks/tests/browser.cjs
```

截图和报告默认放在根目录 `tmp/starblocks-qa/`，不提交到仓库。测试使用独立浏览器上下文，不会修改用户的真实存档。为快速验证后期流程，部分测试会准备材料、传送到交互点；这不是从零到通关的完整人工游玩证明。

已验证规则测试，以及桌面渲染 / 移动 / 喷气背包 / 扫描 / 实际长按采矿 / 放置 / 存档恢复 / 制造 / 四星球旅行 / 星门条件、390 × 844 竖屏、844 × 390 横屏和 1366 × 768 触屏桌面。触屏通过浏览器多点触摸事件仿真，未在实体 Windows 触屏硬件上测试。
